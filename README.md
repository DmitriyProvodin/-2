# E-commerce OOP Project

Реализация базового ядра для e-commerce проекта на Python с использованием ООП.

## Возможности
- Классы `Product` и `Category`
- Подсчёт количества категорий и товаров
- Загрузка данных из JSON
- Покрытие тестами с использованием pytest

## Запуск
```bash
poetry install
poetry run python src/main.py
